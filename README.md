# Portfolio

My personal developer portfolio — a dark-mode, terminal-inspired site showcasing my web development projects, built and deployed from scratch.

🔗 **Live site:** [portfolio-cyan-rho-93.vercel.app](https://portfolio-cyan-rho-93.vercel.app)

## Overview

A single-page portfolio site with a dark, developer-focused aesthetic (monospace accents, terminal-inspired styling) built to link from my LinkedIn and Upwork profiles. Includes a hero section, project showcase, and direct contact options.

## Features

- 🎨 Dark mode / terminal-inspired design with monospace accents
- 📱 Fully responsive layout
- 💼 Project showcase linking to live demos and GitHub repos
- 💬 WhatsApp quick-contact button
- ✉️ Direct contact section (email, LinkedIn, Upwork)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Deployed on [Vercel](https://vercel.com)

## Running Locally

```bash
git clone https://github.com/ali-sher-makki/portfolio.git
cd portfolio
```

Then just open `index.html` in your browser — no build step or dependencies required.
